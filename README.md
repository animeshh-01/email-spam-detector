# 📧 Email Spam Classifier

A machine learning-based web application that classifies emails as spam or not spam using Natural Language Processing (NLP) techniques.

## 🚀 Features
- Detects spam emails using a trained ML model
- Simple and user-friendly web interface
- Real-time prediction
- Efficient text preprocessing using NLP

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- HTML/CSS
- NLP (TF-IDF / Count Vectorizer)

## 📂 Project Structure
- app.py → Flask web application
- model.pkl → Trained ML model
- templates/ → HTML frontend files
- static/ → CSS files

## ▶️ How to Run
1. Clone the repository

2. Install dependencies:
pip install -r requirements.txt

3. Run the application:
python app.py

4. Open your browser and go to:
http://127.0.0.1:5000/
